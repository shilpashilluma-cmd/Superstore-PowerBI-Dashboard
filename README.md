Power BI Interactive Sales Dashboard

This project presents an interactive dashboard built using Power BI.

Key Features:
- KPI Cards (Total Sales, Profit, Orders)
- Sales by Category Analysis
- Time-Series Sales Trend
- Region-based Slicer for Interactivity

Objective:
To provide business stakeholders with actionable insights using data visualization.

Tool Used:
Power BI Desktop

Dataset:
Superstore Sales Dataset
